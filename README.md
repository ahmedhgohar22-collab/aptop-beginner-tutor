# aPToP Beginner Interactive Tutor

Local study app for Eric C.R. Hehner’s *a Practical Theory of Programming* (2026-11-1), ordered by the course lecture timetable.

## Run

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Features

- Micro-cards with gated checks (Show me marks Needs review)
- Proof steppers (connector + law)
- Midterm practice (lectures One–Four by default)
- Glossary, notation tools, local progress in `localStorage`

Lessons are original beginner explanations in the book’s notation. The footer credits Hehner’s free edition.
